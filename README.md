# Taniti Tourism UX Design

A user-experience design project for a fictional tourism website focused on helping travelers quickly find lodging, transportation, dining, attractions, and trip-planning information for the island of Taniti.

## Project Focus

The project followed a full UX workflow from research and planning through wireframing, usability testing, iteration, and interactive prototyping.

## UX Process

```text
Business Requirements
        ↓
User Research
        ↓
Persona Development
        ↓
Information Architecture
        ↓
Low-Fidelity Wireframes
        ↓
Guerrilla Usability Testing
        ↓
Design Revisions
        ↓
Interactive Figma Prototype
        ↓
Usability Task Validation
```

## User Persona

The primary persona represents a traveler planning a 5–7 day vacation with a spouse.

Key goals included:

- Finding activities and attractions
- Comparing lodging options
- Understanding transportation choices
- Accessing booking information quickly
- Using the site comfortably from a mobile device

Primary frustrations included confusing navigation, difficult-to-find information, missing booking links, and poor mobile usability.

## Information Architecture

The site was organized around the most important traveler needs, including:

- Home
- Things to Do
- Lodging
- Transportation
- Dining
- Travel Information

The navigation structure was designed to keep common trip-planning information easy to locate without forcing users through unnecessary steps.

## Wireframing

Low-fidelity wireframes were created before the interactive prototype to establish:

- Page hierarchy
- Navigation structure
- Content placement
- Card-based destination and activity layouts
- Lodging information
- Trip-planning calls to action
- Mobile-friendly page organization

## Usability Testing

Three users participated in guerrilla usability testing.

The testing showed that the overall navigation was understandable and information was generally easy to locate, while also identifying several improvements worth making.

### Feedback Incorporated

The design was revised based on user feedback to:

- Increase the size and emphasis of descriptive text for improved readability
- Replace placeholder imagery with destination-related visuals
- Add lodging filters so travelers can narrow options by needs such as guest count, bedrooms, and lodging type

The navigation structure remained mostly unchanged because testers consistently found it easy to understand.

## Usability Tasks

The finished prototype was designed to support tasks such as:

- Finding information about visiting the volcano
- Locating available lodging
- Reviewing island transportation options
- Finding dining information
- Identifying important travel information such as local currency
